# 聯絡表單 → Google 試算表 設定教學

`contact.html` 上的「預約免費諮詢」表單，需要搭配一個 Google 試算表 + Apps Script 才能真正收到客戶填寫的資料。請依照以下步驟設定（約 5 分鐘），設定好之後告訴我部署後拿到的網址，我會幫你貼到網站程式碼裡並上線。

## 步驟 1：建立 Google 試算表

1. 前往 [Google 試算表](https://sheets.google.com)，建立一份新的空白試算表。
2. 幫它命名，例如「納醫芽官網 - 預約名單」。

## 步驟 2：貼上 Apps Script 程式碼

1. 在試算表上方選單點選 **擴充功能 → Apps Script**。
2. 把原本編輯器裡的範例程式碼全部刪除，改貼上本資料夾中 `contact-form-handler.gs` 的內容。
3. 按上方的「儲存」（磁片圖示），可以幫這個專案命名，例如「聯絡表單接收」。

## 步驟 3：部署為網頁應用程式（Web App）

1. 點選右上角藍色的 **部署 → 新增部署作業**。
2. 點選左邊齒輪圖示，選擇類型：**網頁應用程式**。
3. 設定如下：
   - 說明：可填「聯絡表單」
   - 執行身份：**我**
   - 具有存取權的使用者：**所有人**
4. 點選「部署」。
5. 第一次部署時 Google 會跳出「授權存取權」的畫面，選擇你的 Google 帳號 → 點選「進階」→「前往（專案名稱）」→ 允許權限。
6. 部署完成後，會出現一組網址，格式類似：

   ```
   https://script.google.com/macros/s/AKfycb.......xyz/exec
   ```

   請把這整串網址複製起來給我。

## 步驟 4：交給我完成串接

把上面拿到的網址貼給我，我會把它填入 `contact.html` 中的 `GOOGLE_SCRIPT_URL` 設定，並自動推送上線。之後只要有客戶送出「立即預約睡眠評估」或聯絡我們表單，資料就會自動新增一列到這份試算表中，欄位包含：送出時間、姓名、電話、Email、感興趣的服務、孩子年齡、希望聯絡時間、問題或需求。

## 之後如何查看資料 / 修改內容

- 想看誰預約了：直接打開這份 Google 試算表即可，每筆送出都會即時新增一列，可以用篩選、排序找資料。
- 想改欄位或通知方式（例如同時寄 Email 通知你）：之後可以再請我幫你修改 `contact-form-handler.gs`，加上 `MailApp.sendEmail(...)` 之類的通知功能。
- 如果之後想換掉這個網址（例如重新部署），一樣把新網址給我即可，不需要自己改程式碼。
